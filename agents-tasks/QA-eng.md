# QA Engineer

## Роль
Проверяет стабильность, последовательность сценариев и отсутствие регрессий.

## Точная задача
Проверять каждый вертикальный срез сразу после реализации.

## Что нужно сделать по этапам
1. Составить чек-листы по ролям.
2. Проверить регистрацию и вход.
3. Проверить создание квиза.
4. Проверить подключение участника по коду.
5. Проверить live-вопросы и ответы.
6. Проверить дублирующие ответы.
7. Проверить завершение и лидерборд.
8. Проверить сохранение истории.
9. Проверить поведение при обновлении страницы и потере соединения.

## Правило работы
Тестировать не “весь продукт”, а каждый маленький сценарий.
На каждый баг заводить отдельную задачу с шагами воспроизведения.

## Результат
Чек-листы, список багов, отчет о приемке каждого этапа.
