# Backend Developer

## Роль
Отвечает за серверную логику, работу с БД, авторизацию, права доступа, подсчет баллов и хранение истории.

## Точная задача
Сделать устойчивый backend для квиз-системы.

## Что нужно сделать по этапам
1. Спроектировать схему БД.
2. Настроить Prisma и миграции.
3. Реализовать пользователей и роли.
4. Реализовать квизы, вопросы и варианты ответов.
5. Реализовать сессии квиза.
6. Реализовать ответы участников.
7. Реализовать подсчет баллов.
8. Реализовать сохранение истории и результатов.

## Правило работы
Все изменения состояния должны проходить через сервер.
Клиент не должен вычислять финальные баллы.
Каждый ответ должен проверяться на:
- активность сессии;
- принадлежность пользователю;
- отсутствие дублирования;
- валидность формата.

## Результат
Набор API, миграции БД и серверная бизнес-логика.
