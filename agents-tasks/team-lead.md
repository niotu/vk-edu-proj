# Product / Tech Lead

## Роль
Отвечает за архитектуру, декомпозицию проекта, порядок реализации, контроль зависимостей между дизайном, фронтендом, backend и realtime-частью.

## Точная задача
Собрать MVP квиз-платформы без лишних функций.
Определить границы версии 1.0:
- регистрация и авторизация;
- роли participant / organizer;
- создание квиза;
- live-сессия по room code;
- ответы в реальном времени;
- подсчет очков;
- лидерборд;
- история участия.

## Что нужно сделать по этапам
1. Зафиксировать список сущностей БД.
2. Описать user flow для организатора и участника.
3. Разбить продукт на вертикальные срезы.
4. Согласовать API-контракт между фронтом и backend.
5. Определить события Socket.IO.
6. Утвердить критерии готовности для каждой задачи.
7. Контролировать интеграцию и приемку.

## Порядок реализации
1. Сначала макеты и схема БД.
2. Потом auth.
3. Потом CRUD квизов.
4. Затем live-сессии и Socket.IO.
5. Затем лидерборд.
6. Затем история и тестирование.

## Результат
Документ с архитектурой, списком сущностей, этапами и правилами разработки.
