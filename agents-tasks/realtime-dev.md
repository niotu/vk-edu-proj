# Realtime / WebSocket Developer

## Роль
Отвечает за Socket.IO, синхронизацию комнаты, показ вопросов в реальном времени и рассылку лидерборда.

## Точная задача
Сделать live-режим квиза:
- подключение по room code;
- вход в комнату;
- старт квиза;
- показ вопроса всем;
- таймер;
- прием ответов;
- блокировка после окончания времени;
- обновление лидерборда.

## Что нужно сделать по этапам
1. Поднять Socket.IO сервер.
2. Реализовать создание комнаты.
3. Реализовать join-room.
4. Реализовать start quiz.
5. Реализовать show question.
6. Реализовать answer submit.
7. Реализовать leaderboard update.
8. Реализовать закрытие комнаты.

## Правило работы
Вся логика времени должна контролироваться сервером.
Клиент только отображает состояние.
Нельзя доверять клиентскому таймеру.

## Результат
Стабильный realtime-канал для одного активного квиза.
