# DevOps / Release Engineer

## Роль
Отвечает за сборку, окружения, деплой, переменные, логи и стабильный запуск.

## Точная задача
Подготовить инфраструктуру для локальной разработки и публикации MVP.

## Что нужно сделать по этапам
1. Настроить Docker для PostgreSQL.
2. Настроить .env для всех сервисов.
3. Настроить CI для проверки сборки и тестов.
4. Настроить деплой фронтенда и сервера.
5. Проверить работу WebSocket в прод-окружении.
6. Настроить логирование ошибок.
7. Проверить резервное копирование данных.

## Правило работы
Сначала локальное окружение, потом staging, потом production.
Не выпускать необкатанную realtime-часть сразу в прод.

## Результат
Рабочее окружение и понятная схема деплоя.
