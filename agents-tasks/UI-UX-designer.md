# UI / UX Designer

## Роль
Проектирует интерфейсы и пользовательские сценарии в Miro и Figma.

## Точная задача
Сделать понятные экраны для двух типов пользователей:
- organizer;
- participant.

## Что нужно сделать по этапам
1. Составить карту экранов.
2. Описать сценарии:
   - регистрация;
   - вход;
   - создание квиза;
   - запуск квиза;
   - подключение по коду;
   - прохождение вопросов;
   - экран результата;
   - история.
3. Сделать wireframes.
4. Сделать UI-kit.
5. Собрать кликабельный прототип.
6. Подготовить спецификацию для разработки.

## Правило работы
Не проектировать сразу весь продукт в финальном виде.
Сначала делать только базовые экраны для MVP.
Каждый экран должен иметь:
- default state;
- loading state;
- empty state;
- error state;
- success state.

## Результат
Ссылка на Miro, ссылка на Figma, список компонентов и описание состояний.
