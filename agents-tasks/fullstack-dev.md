# Full-Stack Developer

## Роль
Собирает клиентскую часть, API-слой, формы, страницы, интеграцию с базой данных и часть бизнес-логики.

## Точная задача
Сделать рабочий интерфейс и серверные ручки для:
- регистрации и входа;
- списка квизов;
- создания и редактирования квиза;
- создания вопросов;
- запуска сессии;
- отображения текущего вопроса;
- отправки ответа;
- просмотра результатов.

## Что нужно сделать по этапам
1. Поднять базовый проект.
2. Подключить стили и роутинг.
3. Сделать auth-страницы.
4. Сделать личный кабинет.
5. Сделать CRUD квизов.
6. Сделать страницу live-квиза.
7. Подключить API к базе.
8. Провести локальное тестирование.

## Правило работы
Каждый шаг должен быть проверяемым отдельно.
Не начинать следующий модуль, пока текущий не проходит базовый сценарий.

## Результат
Фронтенд и backend API для основного MVP.
